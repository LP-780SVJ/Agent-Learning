# DD-W4-D7-05: Discriminative Public Verification and Canonical Runtime State

## Status

Accepted on 2026-08-26.

## Context

The B01 Runtime could repair the source while its broad `tests/auth` command
already passed on the faulty baseline. That command was useful regression
coverage but could not prove the requested behavior. Raw DSML retained in the
conversation also taught the model to repeat a provider dialect until a late
malformed response exhausted the lifetime repair budget.

## Decision

- Split Agent-visible commands into completion-required
  `task_verification_commands` and optional broad `verification_commands`.
- Add one hash-pinned public-test patch per dev task and commit it into the task
  baseline after the fault seed. Every public test must fail on pristine fault
  state before a run is scoreable.
- Keep hidden acceptance outside Runtime and execute it only after the Agent
  stops. Grader reports task verification, regression, hidden acceptance, and
  both pristine-oracle checks separately.
- Cache read-only exploration by canonical action and workspace version. Return
  one cached observation, then stop a second unchanged repeat as no progress.
- Structured compaction summarizes read/search history, changed files,
  workspace version, latest verification, diff inspection, and the remaining
  completion gate. Raw provider output is never compacted.

## Consequences

Broad tests can no longer create false completion evidence. A broken public
oracle is labeled `visible_oracle_not_discriminative`, and the null baseline
remains 0/11. The Agent may still run broad regression during repair, but it
must pass the task test and inspect the final diff before completion.

## Verification

- All 11 hash-pinned public tests fail in their pristine fault workspaces.
- The null Runtime scores 0/11 and never receives hidden paths or output.
- Integration tests cover canonical/raw separation, repair reset, read cache,
  patch-version invalidation, task-vs-regression evidence, and deterministic
  compaction state.
